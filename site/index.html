Tout ce qu’il faut pour un audit sérieux

Les fonctions des outils d’audit payants, dans un outil libre que vous pouvez lire, modifier et héberger.

Un crawler rapide et poli

Moteur en Rust qui explore des milliers de pages en quelques minutes, tout en respectant robots.txt, le Crawl-delay et les serveurs qui demandent une pause.

Des règles claires

Titles, descriptions, H1, canonicals, redirections, liens cassés, sitemaps, pages orphelines… Trois niveaux : erreur, avertissement, info.

Suivi dans le temps

Chaque audit est conservé. Comparez deux audits pour voir ce qui s’est amélioré ou cassé, et planifiez des audits réguliers.

Un poste de travail complet

Rapports filtrables, tableau de toutes les URL, détail d’une page, maillage interne, extraction personnalisée et segments.

Exports et sitemap

CSV, JSON ou rapport HTML autonome à envoyer à un client, et génération d’un sitemap XML des pages indexables.

Branché sur votre IA

Serveur MCP intégré : demandez à Claude ou à un autre assistant de lancer un audit et de résumer les priorités, en langage naturel.

Trois étapes, pas plus

  1. Créez un projet

    Donnez simplement l’adresse de votre site. Réglez le périmètre si besoin (dossiers inclus ou exclus).

  2. Lancez l’audit

    Suivez la progression en direct ; mettez en pause ou arrêtez quand vous voulez.

  3. Corrigez par priorité

    Commencez par les erreurs, exportez la liste pour l’équipe, puis relancez pour vérifier.

Un seul accès pour toute l’équipe

Installez CallistSEO une fois sur le serveur de votre entreprise : toute l’équipe s’y connecte avec le même mot de passe et travaille sur les mêmes audits.

  • Vos données restent sur votre serveur, dans une base SQLite que vous sauvegardez comme un simple fichier.
  • Conteneur Docker durci : utilisateur non-root, lecture seule, aucune capacité système.
  • Le crawler refuse de viser votre réseau interne (protection SSRF).

L’application, pour vous

Tout tourne sur votre ordinateur, sans réseau ouvert ni mot de passe. Elle se met à jour toute seule.

Windows10 et 11, .exe macOSApple Silicon (M1 et +) macOSprocesseur Intel LinuxAppImage

Autres formats : Windows .msi, Linux .deb, Linux .rpm, ou toutes les versions. Préversion non signée : à la première ouverture, Windows propose « Exécuter quand même » (après « Informations complémentaires ») et macOS demande une autorisation dans Réglages, Confidentialité et sécurité.

Pour l’équipe, sur votre serveur

Une image Docker sert l’interface et l’API (amd64 et arm64), avec HTTPS automatique en option.

# dans le dossier deploy/ du dépôt
cp .env.example .env
# CALLISTSEO_IMAGE=ghcr.io/phildaiguille/callistseo:latest
# CALLISTSEO_TOKEN = mot de passe de l'équipe
docker compose pull && docker compose up -d

En ligne de commande

Pour les scripts et la CI : le code retour échoue si de nouvelles erreurs apparaissent.

callistseo crawl https://exemple.fr \
  --max-pages 500 --fail-on error
